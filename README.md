## 🌟 Key Features

### 1. 🧩 5 Unified Puzzle Modalities
- **Classic Wordle**: 1 hidden target word, 6 guesses. Optional Hard Mode.
- **Dordle**: 2 parallel targets solved simultaneously, 7 allowed guesses. Keys split vertically into left/right halves.
- **Quordle**: 4 quad targets in a $2 \times 2$ matrix, 9 allowed guesses. Keys dynamically split into 4 quadrant tiles ($2 \times 2$ mini-quadrants).
- **Octordle**: 8 parallel targets requiring multi-front information extraction across 13 allowed guesses. Features an interactive sticky status ribbon (`[#1✓] [#2•]...`) for one-click navigation, and keys split into 8 vertical micro-stripes.
- **Absurdle (Adversarial Minimax AI)**: Does **not** choose a secret word at the start. Partitions all remaining candidates into up to 243 equivalence buckets ($3^5$) on each guess, dynamically adopting the largest bucket with deterministic minimax tie-breakers to prolong the game as long as mathematically possible!

### 2. 🧮 3Blue1Brown Shannon Information Entropy Engine
- Real-time calculator based on Grant Sanderson’s seminal information-theoretic Wordle formulation:
  $$H(g) = - \sum_{p=0, |B_p| > 0}^{242} P(p) \log_2 P(p)$$
- Evaluates candidate pool shrinkage and expected remaining words:
  $$\text{Expected Remaining} = \sum_{p=0}^{242} P(p) \cdot |B_p| = \sum_{p=0}^{242} \frac{|B_p|^2}{|W|}$$
- Ranks top 10 recommended guesses with expected information gain in **bits** (e.g. `SOARE`: 5.886 bits, `ROATE`: 5.883 bits, `RAISE`: 5.878 bits, `SLATE`: 5.856 bits).
- Distinguishes **Candidates** (words that can win right now) from **Splitters** (exploratory words designed to shatter rhyming traps like `_ATCH`).

### 3. 🎨 Multi-Segment Adaptive Keyboard (`KeyCap`)
- Custom-engineered onscreen keyboard keys that visually slice themselves into 1, 2, 4, or 8 segments matching the active modality.
- Strict hierarchical state priority per segment:
  $$\text{Green (Confirmed)} > \text{Yellow (Present)} > \text{Gray (Absent)} > \text{Neutral (Unused)}$$
- Crisp drop-shadowed typography ensures legibility regardless of underlying segment colors.

### 4. 🔊 100% Procedural Web Audio Engine
- Built on the native browser `AudioContext` with zero `.mp3` or `.wav` network requests (0ms latency, zero 404 risks).
- Synthesizes:
  - **Mechanical Key Tap**: Sine sweep from 440 Hz to 120 Hz with an exponential 40ms decay.
  - **Tile Flip Chimes**: Ascending pitch sweeps ($260 + \text{col} \times 45\text{ Hz}$) triggered at the midpoint of each 3D tile rotation.
  - **Error Shake Buzzer**: Dissonant 6 Hz beat frequency generated by dual sawtooth oscillators at 130 Hz and 136 Hz.
  - **Harmonic Victory Fanfare**: Arpeggiated C-major chord ($C_5 \to E_5 \to G_5 \to C_6$).
  - **Defeat Thud**: Low-frequency sweep from 180 Hz to 40 Hz.

### 5. 🛡️ Strict Two-Pass Duplicate Letter Resolution
- Canonical frequency-bounded matching eliminates amateur coloring bugs (e.g., target `ABBEY` vs guess `BABES` correctly yields `['yellow', 'yellow', 'green', 'green', 'gray']`).
- Base-3 ternary pattern encoder/decoder ($0 \le P \le 242$) eliminates heap allocations in the inner loop.

### 6. 🌐 Deterministic Daily Seeding & 100% Offline Resilience
- Cross-platform 32-bit **Mulberry32 PRNG** seeded by `wordle-infinite-{mode}-{date}` ensures players worldwide receive identical puzzles on any calendar day.
- Bundled offline dictionary (2,315 solutions + 12,540 allowed guesses = 14,855 words) guarantees full gameplay even if the backend is disconnected.

## 🚀 Quickstart Guide

### One-Touch Run (`run.sh`)
```bash
./run.sh
```
This verifies Node.js & Python 3.11+, builds the frontend production bundle, launches the FastAPI backend on port `8000`, launches the Vite frontend on port `5173`, and opens the suite.

### Manual Backend Launch
```bash
cd backend
export PYTHONPATH="."
python3 -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

### Manual Frontend Launch
```bash
cd frontend
npm install
npm run dev
```

## 🔌 API Reference (`/api/v1`)

Interactive OpenAPI documentation is live at `http://127.0.0.1:8000/docs`.

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/api/v1/health` | Diagnostic status & wordlist counts (2,315 solutions, 14,855 total). |
| `GET` | `/api/v1/game/daily` | Deterministic daily targets for a given date and modality. |
| `POST` | `/api/v1/game/evaluate` | Evaluates a guess against 1, 2, 4, or 8 target words. |
| `POST` | `/api/v1/words/validate` | Validates word existence in the 14,855 master dictionary. |
| `POST` | `/api/v1/entropy/hints` | Calculates Shannon entropy bits & candidate shrinkage. |
| `POST` | `/api/v1/absurdle/guess` | Minimax adversarial bucket partitioning step. |
| `POST` | `/api/v1/game/hard-mode/validate` | Validates hard mode green/yellow constraints. |
